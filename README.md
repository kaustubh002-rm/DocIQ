FastAPI | React.js | MongoDB | LangChain | ChromaDB | Groq LLM | HuggingFace Embeddings

• Built an AI-powered document intelligence platform that enables conversational querying over PDF documents using Retrieval-Augmented Generation (RAG).

• Implemented document processing workflows including PDF parsing, text chunking, embedding generation, vector indexing, semantic retrieval, and LLM-based answer generation.

• Leveraged LangChain orchestration with ChromaDB vector storage to perform efficient similarity search across document knowledge bases.

• Developed secure authentication and user-specific document management using JWT and MongoDB.

• Designed RESTful microservices for document upload, retrieval, chat persistence, and AI inference operations.

• Implemented PDF viewer, chat history management, document deletion, and personalized workspace features to enhance user experience.

• Reduced hallucinations by grounding LLM responses with retrieved document context and source-aware retrieval mechanisms.
